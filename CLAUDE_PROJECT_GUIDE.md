四、核心数据流

4.1 用户登录流程 (完整链路)

浏览器 ──POST /api/users/login──▶ Nginx:80 ──代理──▶ Flask:5001
  {phone/email, password}                              │
                                                       ├─ 1. 查 User 表 (用户名/邮箱/手机)
                                                       ├─ 2. Werkzeug.check_password_hash()
                                                       ├─ 3. PyJWT 签发 Token (HS256, 7天有效)
                                                       ├─ 4. 更新 last_login 时间戳
                                                       └─ 5. 返回 {token, user}
浏览器 ◀────────────────────────────────────────────────┘
  │
  ├─ localStorage.setItem('auth_token', token)
  └─ Zustand: login(token, user)

4.2 景点查询 (带缓存的数据流)

浏览器 ──GET /api/destinations?page=1&city=北京&rating=4.5──▶ Flask
                                                              │
  ┌─ 限流检查 ────────────────────────────────────────────────┤
  │  rate_limit('destinations', 100次/分钟)                   │
  │  基于 Redis Sorted Set 滑动窗口                           │
  └───────────────────────────────────────────────────────────┤
                                                              │
  ┌─ 缓存检查 ────────────────────────────────────────────────┤
  │  Redis GET cache_key → 命中? ──Yes──▶ 直接返回 (X-Cache: HIT)
  │  未命中 ↓                                                │
  └───────────────────────────────────────────────────────────┤
                                                              │
  ┌─ SQLAlchemy ORM 查询 ─────────────────────────────────────┤
  │  Destination.query.filter(city=北京).filter(rating>=4.5)  │
  │  .order_by(rating.desc()).paginate(page, per_page)        │
  │  → 参数化查询，自动防SQL注入                              │
  └───────────────────────────────────────────────────────────┤
                                                              │
  ┌─ 写入缓存 ────────────────────────────────────────────────┤
  │  Redis SETEX cache_key 300 (5分钟TTL)                     │
  └───────────────────────────────────────────────────────────┤
                                                              │
浏览器 ◀── {success, destinations[], total, pages} ───────────┘
  │
  └─ 组件中使用: React Query 管理缓存+自动刷新

4.3 AI对话流程 (SSE流式)

浏览器 ──POST /api/chat {messages[]}──▶ Flask
  Authorization: Bearer <JWT>             │
                                          ├─ 1. 验证JWT → 获取user_id
                                          ├─ 2. 限流: rate_limit('chat', 20次/分钟)
                                          ├─ 3. 尝试调用AI (多模型降级):
                                          │      Kimi K2.5 → 失败?
                                          │      → 智谱 GLM-4.6v → 失败?
                                          │      → OpenAI (兜底)
                                          ├─ 4. Response Header:
                                          │      Content-Type: text/event-stream
                                          │      Cache-Control: no-cache
                                          │      X-Accel-Buffering: no
                                          └─ 5. Generator 流式输出:
                                                 逐chunk yield "data: {...}\n\n"

浏览器 ◀── SSE 流 ───────────────────────┘
  │  read stream: "data: {\"type\":\"content\",\"data\":\"北\"}\n\n"
  │  read stream: "data: {\"type\":\"content\",\"data\":\"京\"}\n\n"
  │  ...
  │  read stream: "data: {\"type\":\"done\"}\n\n"
  └─ 逐字渲染 + typing动画

4.4 AI行程生成流程

浏览器 ──POST /api/itinerary/generate──▶ Flask
  {destination: "北京", days: 3}          │
                                          ├─ 1. 查本地景点库: Destination.query.filter(city=北京)
                                          ├─ 2. 构建 Prompt: "为北京生成3日游 + 景点列表[...]"
                                          ├─ 3. 调用 LLM → 获取结构化行程计划
                                          ├─ 4. 写数据库:
                                          │      INSERT INTO trips (user_id, title, status)
                                          │      INSERT INTO trip_items (trip_id, destination_id, day)
                                          └─ 5. 返回 {trip, ai_plan}

浏览器 ◀── {success, trip, ai_plan} ─────┘
  │
  └─ 渲染行程卡片 + 地图标记
