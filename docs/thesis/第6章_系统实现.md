### 6.1.2 用户认证实现

用户认证采用JWT（JSON Web Token）机制，包括用户注册、登录、令牌验证等功能。

**用户注册接口**：
```python
@app.route('/api/auth/register', methods=['POST'])
def register():
    data = request.get_json()
    username = data.get('username')
    password = data.get('password')
    
    # 检查用户名是否已存在
    if User.query.filter_by(username=username).first():
        return jsonify({'code': 400, 'message': '用户名已存在'}), 400
    
    # 创建新用户，密码加密存储
    user = User(
        username=username,
        password_hash=generate_password_hash(password)
    )
    db.session.add(user)
    db.session.commit()
    
    return jsonify({'code': 200, 'message': '注册成功'})
```

**用户登录接口**：
```python
@app.route('/api/auth/login', methods=['POST'])
def login():
    data = request.get_json()
    username = data.get('username')
    password = data.get('password')
    
    # 查找用户并验证密码
    user = User.query.filter_by(username=username).first()
    if not user or not check_password_hash(user.password_hash, password):
        return jsonify({'code': 401, 'message': '用户名或密码错误'}), 401
    
    # 生成JWT令牌
    token = jwt.encode({
        'user_id': user.id,
        'exp': datetime.utcnow() + timedelta(days=7)
    }, app.config['JWT_SECRET_KEY'], algorithm='HS256')
    
    return jsonify({
        'code': 200,
        'data': {'token': token, 'user': user.to_dict()}
    })
```

**实现说明**：
- 密码使用werkzeug的`generate_password_hash`函数加密，采用PBKDF2算法
- JWT令牌有效期为7天，包含用户ID和过期时间
- 登录成功后返回令牌和用户信息，前端存储令牌用于后续请求

### 6.1.3 景点管理实现

景点管理模块提供景点的增删改查功能，以下为景点列表接口的实现：

```python
@app.route('/api/destinations', methods=['GET'])
def get_destinations():
    # 获取查询参数
    page = request.args.get('page', 1, type=int)
    per_page = request.args.get('per_page', 20, type=int)
    city = request.args.get('city')
    keyword = request.args.get('keyword')
    
    # 构建查询
    query = Destination.query
    
    # 按城市筛选
    if city:
        query = query.filter_by(city=city)
    
    # 关键词搜索
    if keyword:
        query = query.filter(
            Destination.name.contains(keyword) |
            Destination.description.contains(keyword)
        )
    
    # 按评分降序排序，分页查询
    pagination = query.order_by(
        Destination.rating.desc()
    ).paginate(
        page=page, 
        per_page=per_page, 
        error_out=False
    )
    
    # 转换为字典格式
    destinations = [d.to_dict() for d in pagination.items]
    
    return jsonify({
        'code': 200,
        'data': destinations,
        'pagination': {
            'page': pagination.page,
            'per_page': pagination.per_page,
            'total': pagination.total,
            'pages': pagination.pages
        }
    })
```

**实现说明**：
- 支持按城市筛选和关键词搜索
- 使用SQLAlchemy的`paginate`方法实现分页
- 返回分页信息便于前端展示分页控件

## 6.2 AI对话功能实现

AI对话功能是系统的核心特色，采用SSE（Server-Sent Events）技术实现流式响应，让用户实时看到AI生成的内容。

### 6.2.1 流式响应原理

SSE是一种服务器向客户端推送数据的技术，与WebSocket相比，SSE更简单，基于HTTP协议，适合服务器向客户端单向推送数据的场景。

**SSE工作流程**：
1. 客户端发起HTTP请求
2. 服务器设置响应头`Content-Type: text/event-stream`
3. 服务器持续发送数据块，格式为`data: 内容\n\n`
4. 客户端通过EventSource API接收数据

### 6.2.2 Go AI服务实现

Go语言实现的AI服务负责调用大语言模型API，处理流式响应：

```go
// moonshot_service.go - 调用MiMo大模型API
func (s *MoonshotService) ChatStream(messages []Message, writer io.Writer) error {
    // 构建请求体
    reqBody := ChatRequest{
        Model: "mimo-v2.5-pro",
        Messages: messages,
        Stream: true,  // 启用流式响应
    }
    
    // 发送HTTP请求到MiMo API
    resp, err := http.Post(
        "https://api.mimo.com/v1/chat/completions",
        "application/json",
        bytes.NewBuffer(jsonBytes),
    )
    
    // 逐行读取流式响应
    scanner := bufio.NewScanner(resp.Body)
    for scanner.Scan() {
        line := scanner.Text()
        if strings.HasPrefix(line, "data: ") {
            data := strings.TrimPrefix(line, "data: ")
            if data == "[DONE]" {
                break
            }
            
            // 解析JSON数据
            var chunk ChatCompletion
            json.Unmarshal([]byte(data), &chunk)
            
            // 写入响应流
            content := chunk.Choices[0].Delta.Content
            writer.Write([]byte("data: " + content + "\n\n"))
        }
    }
    
    return nil
}
```

### 6.2.3 Flask代理实现

Flask后端作为代理，转发前端请求到Go AI服务：

```python
@app.route('/api/agent/chat', methods=['POST'])
@jwt_required()
def agent_chat():
    data = request.get_json()
    message = data.get('message')
    session_id = data.get('session_id')
    user_id = get_jwt_identity()
    
    # 保存用户消息到数据库
    conversation = AiConversation(
        user_id=user_id,
        session_id=session_id,
        role='user',
        content=message
    )
    db.session.add(conversation)
    db.session.commit()
    
    # 调用Go AI服务，流式返回响应
    def generate():
        response = requests.post(
            'http://localhost:8084/chat',
            json={'message': message, 'session_id': session_id},
            stream=True
        )
        
        for chunk in response.iter_content(chunk_size=None):
            yield chunk
    
    return Response(
        generate(),
        mimetype='text/event-stream',
        headers={
            'Cache-Control': 'no-cache',
            'X-Accel-Buffering': 'no'
        }
    )
```

**实现说明**：
- 使用Flask的`Response`对象返回流式响应
- `mimetype='text/event-stream'`告诉客户端这是SSE流
- `Cache-Control: no-cache`禁用缓存，确保实时性
- `X-Accel-Buffering: no`禁用Nginx缓冲

### 6.2.4 前端SSE接收实现

Next.js前端通过EventSource API接收流式响应：

```typescript
// assistant/page.tsx - AI助手页面
const sendMessage = async (message: string) => {
    // 添加用户消息到界面
    setMessages(prev => [...prev, { role: 'user', content: message }]);
    
    // 创建SSE连接
    const eventSource = new EventSource(`/api/agent/chat?message=${encodeURIComponent(message)}`);
    
    let aiResponse = '';
    
    eventSource.onmessage = (event) => {
        const data = event.data;
        
        if (data === '[DONE]') {
            // 流式响应结束
            eventSource.close();
            return;
        }
        
        // 拼接AI响应内容
        aiResponse += data;
        
        // 更新界面显示
        setMessages(prev => {
            const newMessages = [...prev];
            const lastMessage = newMessages[newMessages.length - 1];
            
            if (lastMessage.role === 'assistant') {
                lastMessage.content = aiResponse;
            } else {
                newMessages.push({ role: 'assistant', content: aiResponse });
            }
            
            return newMessages;
        });
    };
    
    eventSource.onerror = () => {
        eventSource.close();
    };
};
```

**实现说明**：
- EventSource API自动处理重连和错误恢复
- 每次收到数据块就更新界面，实现打字机效果
- 流式响应结束时关闭连接，释放资源

## 6.4 Redis缓存实现

### 6.4.1 Redis代理类

为了处理Redis不可用的情况，实现了Redis代理类，支持自动降级到内存缓存：

```python
# app.py - Redis代理实现
class RedisProxy:
    def __init__(self):
        self._redis = None
        self._memory_cache = {}
        self._connect()
    
    def _connect(self):
        try:
            self._redis = redis.Redis(host='localhost', port=6379, db=0)
            self._redis.ping()  # 测试连接
        except:
            self._redis = None
            print("Redis不可用，使用内存缓存")
    
    def get(self, key):
        if self._redis:
            try:
                return self._redis.get(key)
            except:
                return self._memory_cache.get(key)
        return self._memory_cache.get(key)
    
    def set(self, key, value, ex=None):
        if self._redis:
            try:
                self._redis.set(key, value, ex=ex)
            except:
                self._memory_cache[key] = value
        else:
            self._memory_cache[key] = value
```

**实现说明**：
- 代理模式封装Redis操作，对外接口保持一致
- 自动检测Redis连接状态，不可用时降级为内存缓存
- 内存缓存使用Python字典，适合开发环境

### 6.4.2 缓存使用示例

在景点列表接口中使用缓存减少数据库查询：

```python
@app.route('/api/destinations', methods=['GET'])
def get_destinations():
    # 生成缓存键
    cache_key = f"destinations:{request.args}"
    
    # 尝试从缓存获取
    cached = redis_proxy.get(cache_key)
    if cached:
        return jsonify(json.loads(cached))
    
    # 缓存未命中，查询数据库
    destinations = Destination.query.all()
    result = [d.to_dict() for d in destinations]
    
    # 写入缓存，设置5分钟过期
    redis_proxy.set(cache_key, json.dumps(result), ex=300)
    
    return jsonify({'code': 200, 'data': result})
```
